Shadcn Date Pickers (AD & BS)

Single and range date pickers in both Gregorian (AD) and Nepali Bikram Sambat (BS) — installed separately with one command each

⚡ Quick Install

Pick the ones you need — AD and BS install independently:

# AD (Gregorian)
npx shadcn@latest add https://www.alishpawn.com.np/r/date-picker.json -y -o
npx shadcn@latest add https://www.alishpawn.com.np/r/date-range-picker.json -y -o

# BS (Nepali / Bikram Sambat) — auto-installs lib/nepali.ts + components/ui/select.tsx
npx shadcn@latest add https://www.alishpawn.com.np/r/date-picker-bs.json -y -o
npx shadcn@latest add https://www.alishpawn.com.np/r/date-range-picker-bs.json -y -o

✨ Features

🗓️ Single Date Picker (AD)

Month navigation, today highlight, clear button, min date support

📅 Date Range Picker (AD)

Quick presets, two-month view, hover range preview, min date support

🇳🇵 Single Date Picker (BS)

Nepali Bikram Sambat calendar with Baishakh–Chaitra month names, year/month selectors

🇳🇵 Date Range Picker (BS)

BS calendar with quick presets, two-month view and shift-by-day buttons

🔁 AD in, BS display

Values stay AD 'YYYY-MM-DD'; the calendar renders in BS via @remotemerge/nepali-date-converter

🧱 Zero shadcn deps

Only lucide-react + cn from @/lib/utils. Works in any shadcn/Tailwind project

🛠️ Usage

AD pickers

import { DatePicker } from "@/components/ui/date-picker";
import { DateRangePicker } from "@/components/ui/date-range-picker";

const [date, setDate] = useState(""); // 'YYYY-MM-DD'
const [range, setRange] = useState({ from: "", to: "" });

<DatePicker value={date} onChange={setDate} min="2024-01-01" />
<DateRangePicker value={range} onChange={setRange} />

BS (Nepali) pickers

import { DatePicker } from "@/components/ui/date-picker-bs";
import { DateRangePicker } from "@/components/ui/date-range-picker-bs";

// Values are still AD 'YYYY-MM-DD' strings; the calendar renders in BS
<DatePicker value={date} onChange={setDate} />
<DateRangePicker value={range} onChange={setRange} />

📦 Props

Prop Type Default Description
valuestring—AD date as 'YYYY-MM-DD' (or { from, to } for range)
onChange(v: string) => void—Called with the new value; '' clears the picker
placeholderstring'Select date' / 'Select date range'Shown when empty
minstring—Earliest selectable date ('YYYY-MM-DD'); AD pickers only
idstring—Passed to the trigger button
classNamestring—Extra classes on the wrapper
name / requiredstring / boolean—Hidden form input (BS single picker only)

🎛️ Customization

Accent color

AD pickers use bg-zinc-900; BS pickers use bg-emerald-600. Swap the class on the selected-day buttons.

Week starts on Monday

AD range picker already uses Monday-start. AD single picker starts Sunday — adjust startOffset and WEEKDAYS.

Locale / formatting

AD display uses toLocaleDateString("en-US", ...). Change the locale string to format for other regions.

Range presets

Edit buildPresets() to add/remove Today, This week, Last month, This year, etc.

🐛 Troubleshooting

🔌 cn() not found

Both pickers import cn from @/lib/utils. shadcn init creates it; otherwise add a lib/utils.ts exporting cn (clsx + tailwind-merge) and the @/* tsconfig alias.

🐘 @remotemerge/nepali-date-converter missing

Re-run the install with -y -o, or npm install @remotemerge/nepali-date-converter manually.

📉 Dropdown clipped by overflow

The calendar is position: fixed and viewport-clamped, so it escapes most containers. Avoid wrapping it in a parent with overflow: hidden + transform (that makes fixed position relative).
